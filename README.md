# Jarvis AI Studio

AI-powered automation studio for building agents, workflows, and media automation.

## Phase 1 — Foundation

Initial foundation for the Jarvis AI Studio platform.

### Planned stack
- Backend: FastAPI + Python
- Frontend: React + Vite + TypeScript
- Database: PostgreSQL
- Cache/queue: Redis
- Authentication: JWT
- Containers: Docker
- CI/CD: GitHub Actions

### Repository structure

```text
jarvis-ai-studio/
├── backend/
├── frontend/
├── docker/
├── docs/
├── scripts/
├── tests/
└── .github/workflows/
```

## Development

Phase 1 is being built incrementally so each milestone can be tested before adding AI agents and YouTube automation capabilities.
